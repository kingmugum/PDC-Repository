# 학습 자료 Index

## 0. 목적

`9. 학습`은 AI / LLM, SW Engineering, ISTQB, SDV, 책·영상 등 개인 학습 자산을 Git과 BoardRepo에서 함께 관리하기 위한 공통 학습 자료 Target이다.

- Git: `9. 학습` 폴더 전체를 이력 관리한다.
- BoardRepo: `9. 학습` 바로 아래의 현재 자료만 일반파일 + SHA-256 방식으로 관리한다.
- `01. old` 및 기타 하위 폴더는 Git에는 보존되지만 BoardRepo 자동 업로드 대상에서는 제외한다.

## 2. 운영 규칙

1. 최신 사용본은 `9. 학습` 바로 아래에 둔다.
2. 과거 버전은 필요 시 `01. old`로 이동한다.
3. 같은 문서의 새 Revision은 문서 자체의 버전 규칙을 따른다.
4. `노트_정리_헌법`의 내용 편집은 해당 문서의 규칙을 우선 적용한다.
5. BoardRepo는 파일명 + SHA-256으로 중복 여부를 판정하며 동일 파일명인데 SHA가 다르면 자동 덮어쓰지 않는다.
6. 학습 자료를 분야별로 더 세분화해야 할 경우 Git 하위 폴더를 사용할 수 있으나, BoardRepo 자동 게시가 필요한 현재본은 Root에 유지한다.
7. 새 분야가 독립 프로젝트 수준으로 커진 경우에만 별도 Automation Manager Target 분리를 검토한다.
