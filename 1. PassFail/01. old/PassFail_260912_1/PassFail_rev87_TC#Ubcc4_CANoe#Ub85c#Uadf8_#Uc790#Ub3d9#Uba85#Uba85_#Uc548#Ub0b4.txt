PassFail rev87 - 차량 송수신 자동 P/F / TC별 CANoe 로그 자동명명 안내
=======================================================================

1. 적용 대상
- `차량 송수신 테스트` 탭의 `선택 TC 자동 P/F 실행`에만 적용합니다.
- 단일 TC 수행 / 다중 TC 수행의 기존 Observer/Judge 동작은 변경하지 않습니다.
- 1안 Replacement 탭은 계속 독립 Dry Run이며 이 기능과 결합하지 않습니다.

2. rev87 Measurement 경계
- 자동 P/F에서 선택한 TC마다 fresh Measurement Start를 수행합니다.
- Stimulus → 출력 Signal 관측 → 짧은 post-release 관측이 끝나면 해당 TC Measurement를 즉시 Stop합니다.
- Stop이 끝난 뒤 로그 이름을 정리하고 다음 TC로 넘어갑니다.
- 따라서 TC 3개를 선택하면 기본적으로 3개의 독립 Measurement 세션이 생성됩니다.

3. 자동명명 동작 조건
- CANoe Configuration에서 Logging이 켜져 있어야 합니다.
- CANoe Logging 저장 폴더와 PassFail `설정` 탭의 `자동 로그 폴더`가 같아야 합니다.
- rev87는 해당 폴더 바로 아래의 .asc / .blf 파일을 대상으로 합니다. 하위 폴더는 자동탐색하지 않습니다.

4. 파일명 규칙
<시트토큰>_<3자리TC번호>-<동일TC내행순번>_<CAN1_DBCstem>_<CAN2_DBCstem>..._<HHMMSS>.<원본확장자>

예)
- Excel sheet : `1. 시트 및 안전장치`
- TC 번호     : 5
- TC 5의 3번째 행
- CAN1 DBC    : B1.dbc
- CAN2 DBC    : M.dbc
- Measurement 시작시각 : 08:34:56
- CANoe 생성 로그 : ASC

=> 시트_005-3_CAN1_B1_CAN2_M_083456.asc

BLF로 Logging 중이면 동일한 규칙으로 `.blf` 확장자를 유지합니다.

5. 안전한 파일 탐색 방식
- Measurement 시작 직전 기존 ASC/BLF의 path + 수정시간 + size를 snapshot합니다.
- Measurement Stop 후 snapshot과 비교하여 이번 세션에서 새로 생성되거나 변경된 로그만 후보로 삼습니다.
- 파일이 안정화된 뒤 rename하므로 CANoe가 쓰는 중인 파일을 임의로 바꾸지 않습니다.
- 같은 이름이 이미 있으면 기존 파일을 덮어쓰지 않고 `_02`, `_03` suffix를 붙입니다.

6. 여러 Logging Block이 있을 때
- 한 Measurement에서 ASC/BLF 여러 개가 동시에 변경되면 rev87는 가장 최근 변경 파일 1개만 규칙명으로 rename합니다.
- 이 경우 AI 분석용 자동 로그에 후보 파일 수와 WARN을 남깁니다.
- 복수 Logging Block 각각을 별도 규칙으로 이름 붙이는 기능은 rev87 범위에 포함하지 않습니다.

7. PASS / FAIL과 로그 이름의 관계
- 로그 이름 자동변경은 증적/추적성 편의 기능입니다.
- Logging이 꺼져 있거나 파일을 못 찾거나 rename에 실패해도 차량 출력 Oracle이 PASS이면 PASS를 유지합니다.
- 이런 경우 상세 결과/AI 로그에 WARN만 기록합니다.
- 단, Measurement Stop 자체가 실패하면 다음 TC와 세션 경계가 불명확해지므로 infrastructure ERROR로 처리합니다.

8. AI 분석용 로그
- txrx_logs/txrx_auto_*_rev87.log 안에 다음 정보를 함께 기록합니다.
  · TC 입력 Stimulus
  · 출력 Expected hit/miss
  · frame count / restore 결과
  · CANoe Measurement 로그의 최종 rename 경로
  · 로그 미탐지/복수 후보/rename WARN

9. 현장 최초 확인 권장
- Seat Forward TC 1개만 선택
- CANoe Logging ON
- 설정 탭 자동 로그 폴더 = CANoe Logging 폴더
- 자동 P/F 실행
- Measurement Stop 후 예: `시트_005-3_CAN1_B1_CAN2_M_HHMMSS.asc` 생성 확인
- 동시에 상단 PASS/FAIL 결과와 출력 Signal hit를 확인
