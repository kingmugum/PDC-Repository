PassFail rev87 - 전체 탭 X/Y 스크롤 및 소형 화면 대응 안내

1. 적용 탭
- 설정
- 단일 TC 수행
- 다중 TC 수행
- 결과 상세
- 차량 송수신 테스트

2. 화면 조작
- 각 탭 오른쪽: 탭 전체 세로 스크롤바
- 각 탭 아래쪽: 탭 전체 가로 스크롤바
- 마우스 휠: 현재 활성 탭 세로 이동
- Shift + 마우스 휠: 현재 활성 탭 가로 이동
- Treeview/로그/Preview 등 자체 스크롤 영역에서는 내부 스크롤을 우선하며, 경계에서 탭 전체 스크롤로 이어집니다.

3. 소형 노트북 대응
- 기존 고정 시작크기 1760x930 및 최소크기 1480x780 강제를 제거했습니다.
- 현재 모니터 해상도에 맞춰 시작 창 크기를 자동 조정합니다.
- 최소 창 크기는 900x600입니다.
- 1366x768 화면 검증에서 초기 창 1286x648로 화면 내부에 들어오는 것을 확인했습니다.

4. 기능 영향
- 본 변경은 UI 배치/탐색만 변경합니다.
- TC 데이터, Vector CANoe/CANalyzer 연결, PASS/FAIL 판정, 로그 재검토, Stimulus, 결과 저장 로직은 변경하지 않습니다.
- 내부 Treeview/ScrolledText의 기존 스크롤바도 유지합니다.
