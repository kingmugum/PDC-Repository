PassFail rev87 - 차량 송수신 테스트 탭 마우스 휠
작성일: 2026-08-10

목적
- rev59에서 추가한 TX/RX 탭 전체 세로 스크롤바를 마우스 휠로도 조작할 수 있도록 사용성을 보강했습니다.

동작 규칙
1. 버튼/라벨/빈 공간에서 마우스 휠
   -> 차량 송수신 테스트 탭 전체가 위/아래로 이동합니다.

2. TC 목록, Preview, 수동 후보 입력, 실험 메모, 송신 상태, 실험 기록,
   차량 출력 수신 결과, TX/RX 실행 로그 위에서 마우스 휠
   -> 해당 내부 영역에 더 볼 내용이 있으면 내부 영역을 우선 스크롤합니다.

3. 내부 영역이 해당 방향의 끝에 도달한 상태에서 계속 마우스 휠
   -> 차량 송수신 테스트 탭 전체 스크롤로 자동 전달됩니다.

4. 다른 탭
   -> TX/RX 전체 스크롤용 마우스 휠 처리는 개입하지 않습니다.

안전/기능 영향
- TC 선택, DBC 분석, Stimulus, CAPL Bridge, 실험 기록, 단일/다중 PASS-FAIL 판정 로직은 변경하지 않았습니다.
- 오른쪽 전체 세로 스크롤바 드래그 기능도 그대로 유지합니다.
