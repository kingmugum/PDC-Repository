PassFail rev85 - 다중 TC 수행 표시/timeout 정책 변경

1. 체크한 TC 행
- 다중 TC 목록에서 체크한 대기 상태 행은 하늘색 음영으로 표시합니다.
- 기존보다 약간 선명한 하늘색과 굵은 글씨로 보강했습니다.

2. PASS 행
- 실시간 PASS 또는 로그 PASS가 확정된 행은 초록색 음영으로 표시합니다.
- PASS 결과 색상이 체크 선택색보다 우선합니다.

3. 다중 수행 자동 timeout 제거
- 다중 동시감시에서는 Excel의 TC 대기시간(기본 30초 등)을 자동 종료 조건으로 사용하지 않습니다.
- 다중 순차실행에서도 각 TC의 realtime timeout을 자동 종료 조건으로 사용하지 않습니다.
- 종료 조건: 전체 선택 TC PASS / 사용자가 [수행 완료] 클릭 / 사용자가 [중단] 클릭.
- 따라서 단순히 30초가 지났다는 이유만으로 미관측 TC가 자동 N/A 확정되지 않습니다.

4. 단일 TC 수행
- 단일 TC 수행 탭의 기존 timeout 정책은 이번 rev85에서 변경하지 않았습니다.
