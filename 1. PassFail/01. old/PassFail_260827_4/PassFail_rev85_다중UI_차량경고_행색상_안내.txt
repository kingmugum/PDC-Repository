PassFail rev85 - 다중 UI / 차량 송수신 경고 / 행 색상 변경 안내
===============================================================

1. 다중 TC 수행 탭 우측 폭 축소
- `다중 실행 설정 / 상태`를 포함한 우측 전체 영역을 약 470px로 고정했습니다.
- 이전에는 minsize만 지정되어 남는 화면 폭을 우측 영역이 다시 가져가 체감상 폭이 줄지 않을 수 있었습니다.
- rev85은 parent column weight=0 + 우측 frame width=470으로 실제 화면 폭을 제한합니다.
- `수행 진행도`, `선택 TC 상세 / 보기`, `다중 실행 결과`도 같은 우측 영역을 공유하므로 동일 폭으로 함께 줄어듭니다.
- 긴 `다중 실행 결과` 열은 내용을 줄이지 않고 내부 horizontal scrollbar로 확인합니다.
- `전체 선택`과 `전체 선택 해제` 버튼은 동일 폭으로 맞췄습니다.
- Start/수행완료/중단 버튼은 우측 470px 안에 들어오도록 최소한만 축소했습니다.

2. 차량 송수신 자동 Stimulus BLOCK 정책 조정
- 시트/등받이/슬라이드/윈도우/도어/선루프/미러 등 body-comfort 물리 작동 TC는 자동으로 BLOCK하지 않습니다.
- 짧은 안전 약어(`str`, `tq`, `hv`)는 단순 부분문자열이 아니라 token 단위로만 판정해 일반 Signal명이 잘못 BLOCK되는 가능성을 낮췄습니다.
- 단, 제동/조향/구동/변속/에어백/고전압/충전/ADAS 등 안전핵심 영역은 기존처럼 자동 Stimulus에서 계속 BLOCK합니다.
- DBC 위치 미확인, 입력 조건 개수 불일치, 출력 조건 없음 등 실행 자체가 성립하지 않는 구조적 BLOCK도 그대로 유지합니다.

3. 테스트 실행 우측 안전 경고 영역
- `테스트 실행` 박스 우측에 `안전 경고` 전용 영역을 추가했습니다.
- 체크한 TC에 시트 관련 항목이 있으면 붉은색 Bold로 다음처럼 표시합니다.
  `반드시 시트 테스트 시, 차량에서 하차 후 진행하세요`
- 여러 body-comfort 항목을 동시에 선택하면 `시트/윈도우/...`처럼 합쳐서 표시합니다.
- 안전핵심 BLOCK TC가 포함되면 자동 Stimulus 제외 안내를 함께 표시합니다.

4. 차량 송수신 목록 행 색상
- 체크만 한 TC: 옅은 파란색
- 실행 후 PASS: 옅은 초록색
- 실행 후 FAIL: 옅은 빨간색
- 실행 후 N/A(미 감지): 옅은 주황색
- ERROR/BLOCK: 옅은 빨간색
- 결과 색상이 체크 색상보다 우선합니다.

5. N/A(미 감지) 판정 의미
- PASS: 모든 출력 Expected가 각각 최소 1회 관측됨
- FAIL: 모든 출력 Signal은 실제로 읽혔지만, 하나 이상 Expected 값에 도달하지 않음
- N/A(미 감지): 출력 조건 중 하나 이상에서 유효한 Signal sample을 한 번도 읽지 못함
- ERROR: Measurement/Stimulus/원복 등 실행 인프라 오류
- N/A는 기능 FAIL로 단정하지 않고 계측/Signal 경로를 먼저 재확인하기 위한 상태입니다.

6. 1안 Replacement 격리
- rev85 변경은 2안 `차량 송수신 테스트` 및 다중 TC GUI에만 적용됩니다.
- `테스트용 P/F 차량 테스트 (1안)`은 기존처럼 별도 optional 모듈이며 두 replacement 파일을 제거해도 기존 5개 탭이 정상 동작해야 합니다.
