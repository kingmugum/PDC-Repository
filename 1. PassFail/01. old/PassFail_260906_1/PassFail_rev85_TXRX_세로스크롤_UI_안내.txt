PassFail rev85 - 차량 송수신 테스트 탭 세로 스크롤 UI 개선
작성일: 2026-08-10

1. 수정 배경
- rev58 차량 송수신 테스트 탭은 한 화면에 모든 영역을 동시에 배치했습니다.
- Windows DPI/모니터 높이에 따라 큰 '송신 설정 / 실행 버튼' 영역의 requested height가 우선 확보되면서,
  상단 TC 목록, 실험 결과 기록, 차량 출력 수신 결과, TX/RX 실행 로그가 매우 얇게 압축될 수 있었습니다.
- 실제 TC 데이터는 존재해도 TC 목록 본문이 거의 보이지 않아 선택할 수 없는 것처럼 보이는 문제가 있었습니다.

2. rev85 변경 내용
- 차량 송수신 테스트 탭 전체를 하나의 세로 스크롤 작업면(Canvas)으로 변경했습니다.
- 탭 오른쪽에 '전체 세로 스크롤바'를 추가했습니다.
- 화면보다 내용이 길면 각 영역을 억지로 압축하지 않고 전체 작업면의 세로 길이를 늘립니다.
- 사용자는 오른쪽 전체 스크롤바를 위/아래로 드래그하여 모든 영역을 확인할 수 있습니다.
- 내부 Treeview/ScrolledText의 기존 자체 스크롤바는 그대로 유지합니다.

3. 기본 표시 높이 확대
- TC 목록: 약 12행
- 선택 TC 입력 송신 Preview: 16행
- 수동 후보 Signal 묶음: 7행
- 실험 메모: 4행
- 송신 상태: 6행
- 실험 기록 Treeview: 7행
- 차량 출력 수신 결과 Preview: 12행
- TX/RX 실행 로그: 10행

4. 사용 방법
- 차량 송수신 테스트 탭 진입 시 가장 위에서 TC 목록을 충분한 높이로 확인합니다.
- TC를 선택하면 Preview/분석 결과가 기존과 동일하게 갱신됩니다.
- 아래쪽 수동 후보/실험 결과/수신 결과/TXRX 로그는 탭 오른쪽 전체 스크롤바를 내려 확인합니다.
- 각 목록이나 텍스트 내부에서 많은 항목을 볼 때는 해당 위젯의 자체 스크롤바를 사용합니다.

5. 영향 범위
- 변경 대상은 차량 송수신 테스트 탭의 레이아웃뿐입니다.
- TC 목록 데이터/선택 이벤트/정적 분석/Stimulus/CAPL Bridge/실험 기록 로직은 변경하지 않았습니다.
- 설정, 단일 TC, 다중 TC, 결과 상세 탭의 레이아웃과 PASS/FAIL 판정 로직은 변경하지 않았습니다.

6. 개발 검증
- 7개 Python/PYW 정적 컴파일 통과
- 1480x780 GUI geometry smoke test:
  * TC 목록 실제 높이 264px(약 12행)
  * TX/RX content 높이 1916px > viewport 705px
  * outer scrollbar yview가 상단에서 하단까지 정상 이동
  * 실험 기록/수신 결과/TXRX 로그가 0 높이로 압축되지 않음

현장 확인 포인트
- 회사 PC의 실제 Windows DPI/모니터 환경에서 TC 목록이 여러 행 보이는지
- 오른쪽 전체 세로 스크롤바로 '실험 결과 기록(수동)' 및 'TX/RX 실행 로그'까지 편하게 이동 가능한지

7. rev85 마우스 휠 조작 추가
- 오른쪽 전체 세로 스크롤바를 직접 드래그하지 않아도 마우스 휠로 TX/RX 전체 작업면을 위/아래 이동할 수 있습니다.
- 버튼/라벨/빈 공간 위에서 휠: TX/RX 전체 작업면 이동
- TC 목록/Preview/수동 후보/실험 메모/상태/실험 기록/수신 결과/실행 로그 위에서 휠:
  1) 해당 내부 위젯에 더 볼 내용이 있으면 내부만 스크롤
  2) 해당 방향 끝에 도달하면 다음 휠부터 TX/RX 전체 작업면으로 자연스럽게 전달
- 내부와 전체 화면이 동시에 움직이는 이중 스크롤은 차단합니다.
- TX/RX 탭이 아닌 다른 탭에서는 이 전체 휠 처리가 동작하지 않습니다.
