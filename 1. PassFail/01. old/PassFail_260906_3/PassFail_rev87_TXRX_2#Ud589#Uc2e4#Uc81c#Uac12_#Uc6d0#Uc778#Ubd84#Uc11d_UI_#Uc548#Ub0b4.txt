PassFail rev87 차량 송수신 테스트 UI 변경

1. 기존 `선택 TC 입력/출력 Preview` 박스를 제거했습니다.
2. `TC 목록 / 자동 차량 P/F`를 확대하고 각 TC를 2행으로 표시합니다.
   - 1행: TC/소분류/입력 기대값/출력 기대값/PASS·FAIL/원인 분석
   - 2행: 자동 수행 중 실제로 읽은 입력/출력 Signal 값
3. 실제 관측값은 기대값을 복사하지 않고 CANoe/CANalyzer Signal read 결과를 사용합니다.
   - 입력은 Active 기대값을 한 번이라도 관측하면 그 값을 유지합니다.
   - 출력은 PASS 기대값을 한 번 관측하면 해당 값을 유지합니다.
   - 끝까지 읽지 못하면 `미감지`로 표시합니다.
4. `자동 진단 요약` 열을 `원인 분석`으로 변경했습니다.
   - PASS: -
   - FAIL: 목표 Signal 값 미 관측
   - N/A: Signal 값 미 감지
   - BLOCK: DBC 미존재/매핑, 복합입력 미지원, 안전핵심 차단 등 실제 차단 사유
   - ERROR: 실행/통신 오류
5. 테스트 실행 박스는 전체 가로폭의 compact 구조로 변경했습니다.
6. 안전 경고는 실행 박스 아래 한 줄로 분리했습니다.
   예: `시트 자동 테스트 수행 시, 반드시 하차하여 진행하세요`
7. `실행 로그 / AI 분석용 (자동 저장)`은 기존대로 유지합니다.
8. 기존 P/F 판정, CRC/Alive/E2E 정책, safety gate, 1안 분리 구조는 변경하지 않았습니다.
