PassFail rev87 - TC 로드 TX/RX 사전분석 / Shift 범위선택 안내
===============================================================

1. 변경 목적
- 기존에는 `TC 목록 로드` 후 차량 송수신 테스트의 특정 TC를 처음 클릭할 때
  DBC/입출력 위치 분석이 수행되어 최초 클릭 시 잠깐의 로딩이 발생했습니다.
- rev87은 이 비용을 `TC 목록 로드` 단계로 이동하여 차량 송수신 탭에서는
  처음 클릭한 TC도 즉시 Preview와 자동 진단 요약을 볼 수 있도록 변경했습니다.
- 차량 송수신 TC 목록에 Shift 연속 범위 선택을 추가했습니다.

2. TC 목록 로드 진행 표시
로드 팝업은 대략 다음 단계로 진행합니다.
- 1/7 Excel 조건 읽기 준비
- 2/7 Excel/TC 조건 읽는 중
- 3/7 차량 송수신 테스트: DBC 사전 로드
- 4/7 차량 송수신 테스트: 입력 송신 대상/자동 진단 요약 사전 분석 (n/N)
- 5/7 화면용 TC 목록 구성 / 표시
- 6/7 차량 송수신 테스트: 사전 분석 결과 적용
- 7/7 후속 캐시/Collector 준비
- 완료 100%

※ Excel parser 자체의 세부 진행률은 단계 기반 표시이고,
   TX/RX 사전 분석 구간은 분석된 TC 수를 기준으로 진행률을 갱신합니다.

3. 왜 이 변경이 타당한가
- 사용 흐름상 TC 목록을 로드한 뒤 TX/RX 탭에서 여러 TC를 조회/선택할 가능성이 높다면
  각 TC 최초 클릭 때 분석하는 것보다 upfront precompute가 사용자 체감이 좋습니다.
- DBC는 TC마다 다시 읽지 않고 mapping 기준으로 1회만 load한 뒤 전체 TC를 분석하므로
  반복적인 DBC load 비용도 줄입니다.
- 단점은 TC 목록 로드 시간이 조금 길어지는 것입니다.
- 이 preload는 DBC read-only 정적 분석이며 CAN/CAPL 송신을 수행하지 않습니다.

4. 최초 클릭 동작
- 정상 preload 완료 TC:
  · 추가 `TC 상세 준비` 팝업 없음
  · Preview 즉시 표시
  · 상단 `자동 진단 요약`도 로드 시점에 이미 표시
- preload 실패 또는 TC 로드 후 DBC를 바꾼 경우:
  · cache miss fallback으로 기존 `TC 상세 준비` 분석을 1회 수행

5. Shift 범위선택
예시:
- 목록 첫 번째 TC를 일반 클릭 또는 체크
- Shift 키를 누른 채 10번째 TC 클릭
- 화면 목록 순서 기준 1~10번째 TC 전체가 체크됨
- 기존에 따로 체크되어 있던 다른 TC는 유지됨
- 첫 클릭한 TC가 anchor로 유지되므로 다시 Shift+다른 TC를 누르면 같은 anchor 기준 범위를 추가 선택할 수 있음

주의:
- Shift는 선택 편의 기능일 뿐 `테스트 실행 준비` 승인 기능이 아닙니다.
- 범위 안에 제동/조향/구동/에어백/고전압/ADAS 등 안전핵심 TC가 포함되더라도
  기존 preflight BLOCK은 그대로 유지됩니다.

6. 검증 결과
- 전체 Python/PYW compile 성공
- Xvfb smoke:
  · 10개 TC preload -> analysis cache 10개
  · 자동 진단 요약 -> PRELOADED summary 표시
  · preload된 TC 최초 클릭 operation popup 0회
  · 1번째 click + Shift+10번째 click -> selected 0~9, count=10
  · anchor=첫 번째 TC 유지
- replacement 두 파일 삭제 사본 -> 기존 5개 탭 정상 실행

7. 현장 확인 권장 순서
1) 설정 탭에서 Excel/시트/DBC 설정
2) `TC 목록 로드`
3) 팝업에 `차량 송수신 테스트: DBC 사전 로드`와
   `입력 송신 대상/자동 진단 요약 사전 분석` 문구가 나오는지 확인
4) 차량 송수신 탭 진입
5) 첫 TC를 클릭했을 때 별도 분석 팝업 없이 즉시 Preview가 나오는지 확인
6) 첫 TC 클릭 -> Shift+10번째 TC 클릭 -> 1~10 전체 체크/파란 음영 확인
