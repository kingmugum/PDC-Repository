PassFail rev87 - 로그 미관측 Actual 표시 개선
================================================

[변경 목적]
로그 파일은 정상적으로 분석되었지만 대상 Signal이 한 번도 나타나지 않았을 때,
기존 GUI는 Actual을 '-'로 표시하고 사유에만 '미관측'을 표시했습니다.
rev87부터 단일 TC 4분할 요약의 입력/출력 '로그 확인' 영역에서 Actual을 '미관측'으로 직접 표시합니다.

[표시 규칙]
1. 정상 로그 재검토 + FAIL + observed_value_raw=None + 미관측 의미
   -> Actual = 미관측
2. 실제 값 관측
   -> Actual = 실제 관측값
3. DBC/Message 오류(ERROR)
   -> Actual = -
4. 사용자 중단(N/A)
   -> Actual = -
5. 로그 결과 자체 없음
   -> Actual = -

[판정 영향]
- Core PASS/FAIL 판정 로직은 변경하지 않습니다.
- 실시간 PASS 우선 정책도 변경하지 않습니다.
- GUI 표시만 명확하게 구분합니다.

[현장 확인]
빈 ASC/BLF 또는 대상 Signal이 없는 로그로 단일 TC 수행 완료 후,
입력/출력 '로그 확인'의 Actual이 각각 '미관측'으로 표시되는지 확인하세요.
