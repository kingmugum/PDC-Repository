260819_2 key change
-------------------
- HEAD/origin Git Tree alias를 실제 Tree 경로 기준으로 case-insensitive resolve
- legacy `6. boardrepo`와 canonical `6. BoardRepo` 상태 비교 호환
- 동일 SHA이면 `동일`; false `원격만 있음` 제거
- 실제 중복 alias만 `확인 필요`
- 자동 case-only rename 금지
- 현재 폴더 Git 연결/복구는 catalog origin URL을 자동 사용 (수동 URL 입력 불필요)

Standard disaster recovery
--------------------------
최신 Automation Manager ZIP 확보 -> 압축 해제 -> Automation_Manager.pyw 실행 ->
[현재 폴더 Git 연결/복구]. 별도 Clone/추가 프로그램 파일 다운로드/Repository URL 재입력은 필수 아님.

Preserved Git policy
--------------------
- main / ff-only Pull
- no force push
- no automatic merge/rebase/conflict resolution
- local files preserved during self-bootstrap
- 1~4 remote-only data hydration; 5~6 root-only; current excluded
- automatic push disabled; older-local push guard retained
