Requirement Studio V0.68 - User Manual Delta
=============================================

1. 3-AI 자동 평가 진행 중 폴더
- 자동 평가가 시작되면 `automatic_evaluation` 폴더에 즉시 다음 파일이 생성됩니다.
  - 00_EVALUATION_STATUS.json
  - 00_EVALUATION_STATUS.txt
  - 06_EVALUATION_EVIDENCE.json
- 따라서 평가 중에도 폴더가 비어 있지 않습니다.
- 각 GPT/Gemini/Claude Reviewer가 끝나는 즉시 해당 JSON/TXT가 추가됩니다.

2. 완료 판정
- `3-AI 자동 평가 완료` 로그는 실제 결과 파일 검증 뒤에만 표시됩니다.
- 완료된 폴더에는 `99_EVALUATION_COMPLETE.ok`가 존재합니다.
- 완료 로그에 Files / FinalParts 수가 함께 표시됩니다.
- 실패 시 `00_EVALUATION_STATUS.txt`에서 실패 단계/메시지를 확인합니다.

3. Gold Source 저장 위치
- V0.68은 프로그램 바깥의 `Requirement_Studio_Gold_Sources` 폴더를 새로 만들지 않습니다.
- 선택적으로 Gold Source를 등록하면 프로그램 내부 `review_exchange/gold_sources/user_registered`에 저장합니다.
- 일반 사용자는 필요한 Source 문서를 기존처럼 `input` 폴더에 넣어 사용하면 됩니다.

4. 요구사항 명세서
- V0.68에서 Requirement_Studio_Requirements_Management_rev55.xlsx 내용은 변경하지 않았습니다.
