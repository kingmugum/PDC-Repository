Requirement Studio V0.68 - Automated Evaluation Setup
======================================================

Evaluation modes remain unchanged from V0.67:
- 3-AI 자동 평가 (추천): Review Package + GPT/Gemini/Claude evaluation
- 수동 평가 패키지만 생성: local Review Package only
- 평가하지 않음: no Review Exchange, no evaluation transmission

V0.68 persistence behavior:
1) automatic_evaluation/00_EVALUATION_STATUS.* is created immediately.
2) 06_EVALUATION_EVIDENCE.json is written inside automatic_evaluation.
3) Each reviewer JSON/TXT is written as soon as that reviewer completes.
4) Consensus/final_result are created after provider collection.
5) On-disk required-file validation runs before completion.
6) 99_EVALUATION_COMPLETE.ok indicates verified completion.

If the UI does not show completion, inspect 00_EVALUATION_STATUS.txt first.
