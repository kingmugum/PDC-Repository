Requirement Studio V0.67 - User Manual Delta
============================================

AI 품질 평가 화면 변경
---------------------
기존 품질 검토 화면의 아래 항목은 제거됩니다.
- 표준 검토
- 중복 검토
- 정밀 검토
- 1차/2차/3차 Reviewer 개별 선택
- 전체/문제 항목 범위 선택
- 개별 Review Criteria ON/OFF

V0.67 평가 모드
---------------
1) 3-AI 자동 평가 (추천)
- Review Package 생성
- GPT/Gemini/Claude 동일 Evidence 독립 평가
- Reviewer JSON/TXT
- Consensus
- Final Result
- final_result 150줄 자동 분할

2) 수동 평가 패키지만 생성
- Review Package 생성
- 외부/H-Chat/API 호출 없음

3) 평가하지 않음
- Review Exchange 생성 안 함
- 자동 평가 호출 안 함
- 기본 분석/SWE 산출물만 생성

주의
----
평가 모델의 실제 Provider/Model은 Evaluation/Provider 설정을 단일 기준으로 사용합니다.
화면의 별도 1차/2차/3차 Reviewer 선택값은 더 이상 존재하지 않습니다.
Reviewer Finding은 Source Evidence가 아니며 Canonical Requirement를 자동 변경하지 않습니다.
