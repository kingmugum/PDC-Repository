# Requirement Studio V0.92

## Structured Basic Functional Test Design
V0.92 keeps the V0.91 human-facing Requirement Master and improves the Fact→Basic Functional TC transformation.

- multi-label Source Fact role classification
- one primary verdict objective per executable TC
- split / keep / vector / step / review decomposition
- structured precondition, environment, input, procedure, observable, expected value/state, PASS criterion
- exact field-level Source Fact Fragment trace
- structured ALL_OF / ANY_OF / INHIBIT transition logic and target state
- review-only routing for Source-undefined Invalid/Error/TBD/Conflict
- eight regression fixture families
- Decision Example Registry scaffold for a future V0.93 Guideline Mining experiment

V0.92 does **not** auto-expand EP/BVA/Fault Injection and does **not** auto-mine/promote user rules.
