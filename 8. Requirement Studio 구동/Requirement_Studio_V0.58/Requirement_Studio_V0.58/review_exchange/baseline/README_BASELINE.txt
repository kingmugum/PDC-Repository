Legacy Baseline Folder (V0.58)
==============================
V0.58은 기존 V0.46-compatible extraction baseline과 Gold Source Registry를 유지합니다.
Explicit-ID 문서는 기존 occurrence/atomic behavior regression을 우선 사용하고,
ID가 없는 Source에는 별도 Semantic Source Unit traceability를 사용합니다.
Semantic fallback은 기존 Gold evidence를 임의 대체하지 않습니다.
