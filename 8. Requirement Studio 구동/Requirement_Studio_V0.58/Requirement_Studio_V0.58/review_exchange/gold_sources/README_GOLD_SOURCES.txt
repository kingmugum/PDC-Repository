Requirement Studio V0.58 Gold Source Registry
=============================================
- Gold Contract 선택 키: Source SHA-256
- SHA가 일치하지 않으면 다른 Gold Contract를 적용하지 않습니다.
- Cross-Document 평가 Source는 사용자 검토·승인 전 자동 Gold 등록하지 않습니다.
- Explicit-ID Gold는 기존 Source occurrence / atomic behavior regression을 유지합니다.
- 향후 no-ID Source를 Gold로 승인할 경우 Semantic Source Unit contract를 별도 baseline으로 확정해야 합니다.

V0.58 추가 원칙
---------------
Gold A만 개선하고 다른 문서가 악화되는 변경은 채택하지 않습니다.
특정 REQ ID, Paragraph 번호, Parameter/Signal 이름을 Production Logic에 하드코딩하지 않습니다.
