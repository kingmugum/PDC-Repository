Requirement Studio V0.44

실행 방법
1) 압축 해제
2) `Requirement Studio.pyw` 더블클릭
3) .pyw 연결이 없는 PC에서는 `pythonw "Requirement Studio.pyw"` 또는 `pyw "Requirement Studio.pyw"` 사용

V0.44 주요 변경
- 사용자 최종 시안을 AI 설정 Card의 단일 Layout 기준으로 적용
- 기존 상충 정렬 Requirement FR-295 / FR-304 / FR-313 / FR-314 삭제
- AI 연결 상태 Badge 높이 약 34px compact pill
- AI Engine 아래 약 28px 간격 후 Model/API Key 배치
- 우측 Provider Action 3개는 동일 기능/폭 유지, 본문 하단 기준 배치
- 남는 Card 높이는 하단 Stretch가 흡수하여 Badge/Header가 비정상 확장되지 않음
- 파일 Drop Zone 크기 고정, Provider-aware Action, ALIRA Native Vision 유지
- SWE.1 Word / SWE.1 Excel / SWE.6 Excel 실제 생성 유지

ALIRA
- verified CLI Image Tool Native Vision 유지
- supports_images=true / vision_transport=cli_image_tool
- Vision 실패는 Visual 단위 failed, Text/Table은 계속

주의
- 실제 *.lic 파일은 ZIP에 포함하지 않습니다.
- 자체 제작 EXE는 포함하지 않습니다.
- V0.44 AI 설정 화면 위치는 Windows 사용자 환경에서 최종 육안 확인이 필요합니다.

- 파일 및 옵션 설정 Card의 드롭 영역 높이를 축소하여 분석 진행 상황/필수 항목 확인 영역이 위로 올라오도록 조정
- AI 설정 Card와 실행 Card는 V0.43 최종 레이아웃을 그대로 유지
