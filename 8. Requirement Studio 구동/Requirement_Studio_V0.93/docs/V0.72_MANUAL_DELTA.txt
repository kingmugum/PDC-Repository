Requirement Studio V0.72 - User Manual Delta
==============================================
- FINAL_RESULT만 전달해도 버전/입력 Source/SHA-256/평가모드/Run ID를 식별할 수 있습니다.
- FINAL_RESULT는 최대 110줄 단위로 분할되며 모든 Part 상단에 식별 헤더가 반복됩니다.
- Provenance Audit는 Structured Source Fact의 identifier/value/timing/enum 정보를 단일 collector로 검사합니다.
- Critical Canonical Fact가 정확한 Source Fact Fragment에 소유되지 않으면 별도 Tool Quality Review로 표시합니다.
- REVIEW_NEEDED Semantic Unit은 자동으로 해결된 것으로 보지 않고 OPEN/non-terminal 상태로 표시합니다.
- SW Allocation Pending, Source Gap, Gold baseline 부재는 Source/거버넌스 상태이며 프로그램이 임의 해결하지 않습니다.
