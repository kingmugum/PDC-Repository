Requirement Studio V0.92 Sample Input Fixtures

목적
- V0.92 구현 전에 Fact 역할 분류, TC 분할, Input/Output/PASS Criterion 구조화,

주의
- 일부 Fixture는 사용자가 제공한 ESTRACK 패턴을 축약/재구성한 것이다.
- 일부 Fixture는 H-Chat 피드백 회귀검증을 위해 의도적으로 만든 합성 사양이다.
- 실제 고객 사양 또는 승인 Requirement로 사용하면 안 된다.
- EP/BVA/결함주입은 이 샘플 세트의 범위가 아니다. 기본 기능 검증만 대상으로 한다.
