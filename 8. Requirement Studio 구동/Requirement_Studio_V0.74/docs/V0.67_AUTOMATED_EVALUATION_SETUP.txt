Requirement Studio V0.67 - Automated Evaluation Setup
=====================================================

Default path: H-Chat
--------------------
config/evaluation_api_config.json:
  "transport": "hchat"

The evaluator reuses Requirement Studio's existing H-Chat credentials/configuration and invokes three independent backends:
- GPT
- Gemini
- Claude

No additional direct-provider key is required when the enterprise H-Chat gateway exposes all three backends.

Optional direct API path
------------------------
Change:
  "transport": "direct_api"

Set environment variables outside the Requirement Studio package:
- OPENAI_API_KEY
- GEMINI_API_KEY
- ANTHROPIC_API_KEY

Default direct models retained from the V0.66 evaluation adapter:
- OpenAI: gpt-6.1-sol
- Gemini: gemini-3.8-flash
- Anthropic: claude-sonnet-5-5

The model IDs are configuration values and may be changed without modifying evaluator logic.

Structured-output adapters
--------------------------
- OpenAI: Responses API / JSON Schema structured output
- Gemini: Interactions API / response_format JSON Schema
- Anthropic: Messages API / output_config.format JSON Schema

Security
--------
- API keys are never written into automatic_evaluation outputs.
- API keys are not included in distribution ZIPs.
- Automatic evaluation transmits the Evaluation Evidence Package to the configured service.
- Disable automatic evaluation when policy does not permit Source/evidence transmission.

Output
------
review_exchange/<run>/automatic_evaluation/

The folder contains three independent evaluator results, consensus, machine-readable final JSON, and a final_result folder split at 150 lines per TXT file.
