Requirement Studio V0.64 -> V0.65 변경 판단서
================================================

1. 변경 목적
-----------
V0.64 실제 SWE.6 Reference Run에서 다음 Release Review 항목이 확인되었다.
- Composite Source Fact Fragment의 multi-SRS allocation conflict
- Table decimal literal(6.5V / 18.5V)의 numbered-list 오인
- Positive SW allocation evidence 없이 System behavior가 SWE.6 Eligible로 승격되는 문제
- 일반 prior/current Run이 regression baseline 후보가 되는 governance 문제
- Tool defect와 Source/External dependency에 따른 Artifact readiness HOLD가 하나의 gate에 혼재

2. V0.65 반영
-------------
A. Composite Fact Ownership Repair
- 문장/newline/bullet/list 외에 강한 action connector 기반 behavior clause fragmentation 추가
- Fragment ownership 비교에서 broad Source Evidence 전체를 제외하고 Canonical behavior를 discriminator로 사용
- 동일 복합 문장을 여러 SRS가 통째로 소유하는 구조를 방지

B. Table / Decimal-aware Splitter
- Table Source Unit에는 ordered-list digit split 비적용
- Numeric marker는 marker 뒤 whitespace + 2개 이상 + 연속 sequence 조건 적용
- decimal/revision/heading/date/spec identifier 보존

C. Positive SW Allocation Evidence Gate
- absence-of-non-SW evidence -> SW 추론 제거
- Source의 명시 SW/S/W wording 또는 Task/ISR/SWC/RTE 등 software structural evidence만 SW promotion 근거로 사용
- 일반 controller/system behavior는 SYSTEM_REQUIREMENT_PENDING_SW_ALLOCATION
- allocation_confidence / software_allocation_evidence_type / positive_sw_allocation_evidence 기록

D. Approved Gold Regression
- Review Exchange history의 일반 최신 Run 자동 baseline 선택 제거
- Gold Source Contract 또는 protected legacy baseline만 regression reference 사용
- Gold contract schema 1.4: approval_status / stable_source_keys 추가
- no-ID Source는 source location + normalized fact text stable key 비교 가능

E. Gate 분리
- Tool Quality Gate: 프로그램 fidelity/invariant 결함
- Artifact Readiness Gate: external dependency / child intent independent coverage / cross-domain readiness
- release_gate_passed는 engineer-facing Artifact Readiness의 호환 alias로 유지

F. TC Maturity
- INTENT_DRAFT / PARTIALLY_TESTABLE / EXECUTION_READY
- Independent Coverage
- Execution Readiness
- SWE.6 Excel V: X에 표시, Result R:U는 그대로 Blank invariant 유지

G. Reference Identifier
- MS/ISO/IEC/SAE/ASTM/KS/UN/IEEE typing 확장

3. Protected Invariants
-----------------------
- Protected Invariants 1.5
- INV-019 Positive SW allocation evidence
- INV-020 Engineering literal / list-marker preservation
- INV-021 Explicit approved Gold only regression
- INV-022 Tool Quality vs Artifact Readiness gate separation

4. 검증
-------
- 기존 V0.51~V0.64 regression 유지
- V0.65 신규 regression 포함 전체 87 tests PASS
- 신규 회귀 항목:
  * 6.5V / 18.5V / 1.3 / 5.4.1.1 literal preservation
  * High Power 실제 1)~4) list recovery 유지
  * Paragraph 82 composite behavior fragment ownership 분리
  * System behavior positive-SW gate
  * S/W / Task/ISR software evidence promotion
  * MS/ISO identifier non-range typing
  * approved Gold no-ID stable-key regression PASS
  * Tool Quality / Artifact Readiness gate separation
  * TC Maturity Excel export
