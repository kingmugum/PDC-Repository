Requirement Studio V0.63
========================

- Requirement Studio.pyw

핵심 원칙:

- Source에 없는 값/신호/시간/DB/시험결과를 생성하지 않습니다.

5) Child Intent: REPRESENTED / INDEPENDENTLY_COVERED / DEFERRED / REVIEW_REQUIRED 분리
6) SWE.6 Audit: PASS / PASS_WITH_REVIEW_ITEMS / FAIL + severity 분리
7) Semantic Table/Appendix/Variant Governance context 정리
8) SWE.6 Excel에 5_Source_Fact_Audit Sheet 추가
