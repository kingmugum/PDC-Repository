Requirement Studio V0.62 Gold Source Registry
=============================================

Gold Source는 특정 문서에 맞춘 하드코딩 근거가 아니라 Regression Contract로 사용합니다.

원칙:
- Source SHA 기반 등록
- Explicit-ID / no-ID Source를 구분
- 기존 Gold Critical Regression 증가 금지
- 새 Gold failure는 문서명/ID 하드코딩이 아니라 generic invariant로만 수정
- Development / Validation / Hold-out Gold를 가능하면 분리
