Requirement Studio Change Decision — V0.77 → V0.78
====================================================

1. Input Evidence
-----------------
V0.77 MLM / ESTRACK CHECK_SITUATION + FINAL_RESULT runs.
Observed outcomes:
- V0.77 practical promotion recovered useful Main SWE.1/SWE.6 candidates.
- Human allocation review is now the dominant policy/governance question.
- Deterministic defects still existed: Deferred Intent summary mismatch, 0X0/0x0 ownership false gap, shared-fragment context ambiguity, mixed-domain operative-field leakage, and MLM non-SW provenance discontinuity.

2. User Direction
-----------------
The user wants human guidance to become reusable policy rather than repeated per-SRS approval work. A first sample may generate many examples, but later samples should reuse previously decided policy patterns and ask only genuinely new questions.

3. V0.78 Scope Decision
-----------------------
V0.78 introduces GUIDE_PERSON question generation only.

- Create `automatic_evaluation/guide_person/guide_person_###.txt` and `guide_person_questions.json`.
- Questions are stable policy families, not one Yes/No prompt per SRS.
- Choices: YES / NO / CONDITIONAL / DEFER.
- Include AI suggested position, observed examples, and cross-document reuse scope.
- Do NOT persist/apply answers automatically in V0.78.
- Human Policy Registry / answer reuse is deferred until question quality is validated across multiple Sources.
- Deterministic Tool defects are never delegated to GUIDE_PERSON.

4. Deterministic Tool Quality Fixes
-----------------------------------
FR-410 Deferred Intent summary single-truth
- Allocation-pending Deferred intents now contribute to summary required/deferred counters before branch continuation.
- CHECK_SITUATION keeps actual XLSX cross-check as an independent verification.

FR-411 Hex token normalization
- `0X0` and `0x0` are the same engineering value for provenance/ownership comparison.
- Raw Source spelling is preserved.

FR-412 Shared Fragment parent-context alias
- A physical Source Fact Fragment with divergent parent allocation/domain claims receives deterministic `SRC-FRAGCTX-*` aliases per parent.
- Each alias preserves `contextual_alias_of` and parent identity.
- Source text is not duplicated as a new fact; this is claim-context modeling.

FR-413 Mixed-domain all-field isolation
- V0.77 isolated Main SWE.1 Requirement Text, but Trigger/Behavior/Precondition/Output/Acceptance could still carry pending SYS.5 facts.
- V0.78 scrubs every operative Main SWE.1 field when excluded facts are materially represented, rebuilding the field from Source-backed Eligible fact scope.

FR-414 Explicit cited non-SW provenance completion
- Exact Source locations already cited by a Not-SW requirement may be added to trace when the unit is high-confidence non-SW and materially overlaps the Canonical content.
- No allocation or requirement is generated by this completion.

5. Preserved Invariants
-----------------------
- No Source fact invention.
- No arbitrary Signal/Timing/Threshold/Test Value generation.
- No silent conflict resolution.
- Inferred SW candidate != approved allocation.
- Execution result fields remain blank before execution.
- OPEN Semantic Units remain non-terminal until dispositioned.
- Gold baseline absence remains NOT_EVALUATED.
