Requirement Studio V0.88
========================

V0.88 is a GUI-responsiveness refinement release on top of the V0.87 Compact E2E baseline.

What changed
------------
1. AI Engine selector uses two rows:
   - Row 1: GPT / Gemini / Claude
   - Row 2: ALIRA / 기타
2. Model/API Key fields use responsive Expanding width with a smaller minimum width.
3. Provider action buttons allow a smaller compact width.
4. Top File / AI / Run cards use a more balanced 3:6:3 stretch ratio.
5. Default window width is 1200 and the logical dashboard minimum width is 1100 so the GUI can shrink before horizontal scrolling is required.
6. The middle analysis progress / required-item panels, E2E outputs, and automatic GPT/Gemini/Claude quality evaluation are unchanged.
7. The temporary GUI requirement-edit exception is closed. LOCK-008 is the default requirement change-control rule again; no existing approved requirement may be edited or deleted without explicit user approval.

No E2E semantics changed
------------------------
- E2E Requirements Word/Excel remains the SYS.1 + SWE.1 + native/review human-facing master.
- E2E Evaluation Excel remains the SYS.5 + SWE.6 + Deferred/External/Native human-facing verification master.
- Recommended Unified E2E evaluation still reviews SWE.1 Word/Excel, SWE.6 Excel, E2E Requirements Word/Excel and E2E Evaluation Excel.
- Automatic 3-AI review remains GPT + Gemini + Claude -> Consensus -> Completeness Audit -> Final Result.
