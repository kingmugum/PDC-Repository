Requirement Studio V0.88 Manual Delta
=====================================

Scope
-----
V0.88 changes only AI Settings / top-dashboard responsiveness and restores normal Requirement change-control boundaries. V0.87 E2E Requirement/Evaluation semantics and automatic 3-AI review are unchanged.

GUI changes
-----------
- AI Engine row 1: GPT / Gemini / Claude
- AI Engine row 2: ALIRA / 기타
- Model/API Key fields are responsive (smaller minimum width + Expanding policy).
- API Key folder / manual input / connection-test buttons use a smaller compact width.
- File / AI / Run top cards use a balanced 3:6:3 stretch ratio.
- Default window width: 1200.
- Dashboard logical minimum width: 1100; below that horizontal scroll may appear.
- 분석 진행 상황, 필수 항목 확인, STEP 1~7, 결과 품질 검토 Compact UI are preserved.

Governance
----------
The temporary GUI-edit allowance used for V0.87~V0.88 does not grant permission to edit unrelated requirements. After this release, LOCK-008 is again the default rule: existing approved Requirement/Lock/Rule/Test/Conflict records are not edited/deleted/replaced without explicit user approval.
