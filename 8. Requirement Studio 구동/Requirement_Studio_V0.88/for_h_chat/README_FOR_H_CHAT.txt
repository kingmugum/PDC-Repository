Requirement Studio — for_h_chat
================================
This folder supports ad-hoc review in an internal H-Chat environment with a 3-file upload limit.

Recommended upload set:
1. Source input document
2. One output/result document you want reviewed
3. Requirement_Studio_HChat_Context_V0.88.txt

00_RECENT_CHANGES_V0.88.txt is a quick version-delta reference.
The Context Pack is deliberately curated and size-bounded; it is not authoritative source evidence and is not a full source-code archive.
