Requirement Studio - ALIRA 라이선스 폴더

1. 발급받은 ALIRA 라이선스 파일(*.lic)을 이 폴더에 넣습니다.
2. 파일명은 반드시 license.lic일 필요는 없습니다. 폴더 안의 최신 *.lic 파일을 사용합니다.
3. Requirement Studio는 라이선스를 ALIRA 설치 폴더로 복사하지 않고,
   ALIRA 실행 시 ALIRA_LICENSE_PATH 환경변수로 이 파일을 전달합니다.
4. 라이선스 파일 자체는 배포 ZIP에 포함하지 마세요.

ALIRA CLI가 PC에 없으면 [ALIRA 연결 설정] 창에서 사용자의 확인을 받은 뒤
사내 공식 Windows 설치 스크립트로 로컬 CLI 설치를 진행할 수 있습니다.
실제 Qwen 모델은 로컬에 설치하지 않고 사내 vLLM 서버에 연결합니다.
