Git 복구와의 관계
-----------------
BoardRepo는 GitManager/BoardRepo ZIP을 게시판에서 업로드/다운로드할 수 있습니다.
그러나 다운로드 직후 .git을 만들거나 Commit/Push하지 않습니다.
Git 연결/복구는 사용자가 Git Manager 탭에서 '현재 폴더 Git 연결/복구'를 명시적으로 실행할 때만 수행됩니다.
