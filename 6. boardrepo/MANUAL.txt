[그룹웨어 로그인 정보]
- 상단 [로그인 정보 저장/갱신]에서 ID/PW를 미리 저장할 수 있습니다.
- 기존 ID가 저장되어 있으면 ID 입력창에 자동 표시됩니다.
- 저장 위치는 Windows 운영체제 자격 증명 저장소(keyring)이며 config.json/ZIP에는 비밀번호가 저장되지 않습니다.

[비밀번호가 바뀐 경우]
1. BoardRepo가 저장된 정보로 자동 로그인을 시도합니다.
2. 명시적 계정정보 오류 또는 로그인 화면 지속이 감지되면 '그룹웨어 로그인 정보 갱신' 창이 표시됩니다.
3. 기존 ID는 읽기 전용으로 유지됩니다. 새 비밀번호만 입력하고 [저장 후 다시 로그인]을 누릅니다.
4. 새 비밀번호 저장 후 중단된 업로드/다운로드 작업을 자동으로 다시 시도합니다.
5. CAPTCHA/MFA/보안문자가 보이면 비밀번호 오류로 단정하지 않고 브라우저에서 직접 인증을 기다립니다.

※ 로그인 실패는 비밀번호 변경 외에도 계정 잠금, 네트워크, 그룹웨어 정책 변경 때문일 수 있습니다.


[오프라인 준비 v0.36]

- 의존성 기준: playwright 1.62.0 / keyring 25.7.0 / greenlet 3.5.6
- 기존 greenlet 4.x가 남아 있어도 새 준비는 staging에서 완료 후 교체하므로 재충돌을 방지합니다.
- 기존 패키지에서 준비에 실패했다면 새 버전에서 [회사용 오프라인 준비]를 다시 실행하세요.
